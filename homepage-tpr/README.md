# The People's Room

Homepage responsive realizzata in HTML, CSS e JavaScript, senza screenshot della pagina o cornici del computer.

## Contenuto

- logo vettoriale, cinque personaggi e forme organiche ricavati dall'export Figma originale;
- titoli display principali e titoli delle room estratti dai tracciati originali, quindi fedeli anche senza il font installato;
- immagini originali ad alta risoluzione per hero, room, eventi, membership e app;
- palette Figma: Royal Blue `#2C64E8`, Blue Ice `#98CAFF`, Green `#3F9941`, Orange `#EB642B`, Yellow `#FFC100`, Pink `#FF7BFF`, Yellow Green `#C2D569`;
- carousel animato per Coworking, Reformer, Wellness, Bar e Media;
- menu accessibile, focus trap, supporto tastiera e `prefers-reduced-motion`;
- layout desktop, tablet e mobile realmente responsive e scrollabile.

I font indicati nel file Figma sono **PP Rader Semibold** per i titoli e **Alte Haas Grotesk Regular** per il testo. I titoli visivi principali sono già riprodotti dai tracciati Figma; per rendere identico anche tutto il testo HTML servono i relativi file webfont con licenza (`.woff2`, `.woff`, `.otf` o `.ttf`). Il PDF esportato contiene soltanto glifi Type3 convertiti in tracciati e non incorpora alcun file font riutilizzabile. Il CSS usa i font quando installati e applica fallback compatibili in loro assenza.

Questa copia recuperata usa gli asset condivisi nella cartella sorella `../assets/`, senza duplicarli.

Con il server del progetto è disponibile su `http://127.0.0.1:4173/homepage-tpr/`.
